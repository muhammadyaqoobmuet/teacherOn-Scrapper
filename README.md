# TeacherOn CS Jobs Scraper

A web scraper that extracts Computer Science related tutoring jobs from TeacherOn.com.

## Requirements

- Node.js 18+
- npm

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/teacheron-scraper.git
cd teacheron-scraper

# Install dependencies
npm install

# Install Playwright browsers
npx playwright install
```

## Usage

```bash
node index.js
```

The scraper will:
 Scrape job listings from all pages Filter for CS-related keywords Visit each job page for detailed info


## Output
saved on json file
